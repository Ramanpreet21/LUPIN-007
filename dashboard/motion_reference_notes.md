# Motion Icon Reference Notes

The supplied 13-second reference presents a dense field of thin, monochrome outline icons on a black field. The visual language is precise and technical rather than illustrative: consistent stroke weight, compact spacing, discrete icon states, and subtle high-frequency motion implied by the video reference. The dashboard adaptation will preserve its existing ion-mint Liquid Glass palette while applying restrained, state-driven micro-motion to operational icons instead of importing the reference artwork directly.

Detailed video analysis confirms a draw-on stroke treatment, state morphing rather than hard cuts, small elastic rotation/settling, staggered sequencing, and slow breathing pulses for active states. The dashboard translation uses animated Lucide strokes on hover/focus, staggered rail-icon entry, gentle active-status breathing, and an interaction-time depth response. It deliberately avoids copying the reference icon artwork.
